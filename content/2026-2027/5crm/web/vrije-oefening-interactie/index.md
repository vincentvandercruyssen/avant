## Briefing & Concept
Een vrije technische en creatieve oefening om los van de vaste thema's te experimenteren met geavanceerde CSS transitions, transformaties en interactieve UI state management met JavaScript.

## Afspraken & Fasering
- **Fase 1: Componentontwerp**
  Kies een UI component (zoals een interactieve kaart, toggle button, accordeon of dynamisch zoekveld) en schets de hover- en active states.
- **Fase 2: CSS Custom Properties & Transities**
  Bouw de semantische HTML en implementeer vloeiende CSS transities met behulp van custom cubic-bezier timing functions.
- **Fase 3: JavaScript Events & Feedback**
  Koppel JavaScript event listeners om state classes te beheren en geef directe visuele feedback aan de gebruiker.
